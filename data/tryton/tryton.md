## Overview

Tryton is an open-source ERP originally forked from TinyERP, featuring a cleaned-up code base with a continuous update and migration path.

## License and Platform

- Platform: Python, PostgreSQL, GTK+, JavaScript
- License: GPLv3
- Origin: Worldwide
- Last stable release: 2023-10 (7.0)
