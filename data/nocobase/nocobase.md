## Overview

NocoBase is an open-source platform for building, running, and evolving business systems with AI. Agents write the code and do the work, NocoBase provides the foundation and governance, and people make the decisions.

## Features

- Open-source business system platform
- AI-powered application development
- Multi-tenancy support
- Extensible plugin architecture
- Self-hosted deployment
