## Overview

Carbon is an open-source manufacturing ERP, MES and QMS platform. It provides quoting, MRP, inventory, shop floor management, quality control, and lot/serial traceability on one Postgres schema, with a REST API and MCP server.

## Features

- Open-source manufacturing ERP
- MES (Manufacturing Execution System)
- QMS (Quality Management System)
- Quoting and MRP
- Inventory management
- Shop floor management
- Quality and lot/serial traceability
- REST API and MCP server
- Single Postgres schema
- Self-host or use Carbon Cloud

## Pricing

Open-source; self-hosted option available. Carbon Cloud is a hosted service (pricing on website).
